# ZeroFall v1.1.0 更新日志

## 新增功能

### 1. 启动自检加载进度条
- ACE风格的启动加载界面
- 实时显示自检进度和百分比
- 详细的自检步骤列表（11项检查）
- 检查项包括：
  - 系统配置加载
  - 日志引擎初始化
  - DeepSeek路径检测
  - 插件目录扫描
  - 快照索引加载
  - MD5基线校验
  - 会话完整性校验
  - 环境健康评估
  - 守护进程初始化
  - 云端连接检测
  - 系统就绪检查

### 2. 系统托盘图标优化
- 使用 Windows 原生 API 创建托盘图标
- 强制图标始终显示在任务栏（不隐藏在溢出菜单）
- 支持右键菜单
- 支持双击显示主窗口

### 3. 界面改进
- 深色主题设计
- 渐变进度条效果
- 状态图标颜色区分（通过/警告/失败）
- 自检完成后自动切换到主界面

## 技术改进

### 新模块
- `ui/loading_overlay.py` - 加载覆盖层和自检工作线程
- `ui/native_tray.py` - 原生系统托盘图标（Win32 API）

### 架构优化
- 使用 QStackedWidget 管理加载页和主界面切换
- 异步自检流程，不阻塞 UI
- 自检完成后延迟切换，提升用户体验

## 文件变更
- 修改: `ui/main_window.py` - 集成加载界面和原生托盘
- 新增: `ui/loading_overlay.py` - 加载覆盖层
- 新增: `ui/native_tray.py` - 原生托盘图标

## 使用说明
1. 双击启动 ZeroFall.exe
2. 等待自检完成（约3-5秒）
3. 自检完成后自动进入主界面
4. 系统托盘图标始终显示在任务栏右下角
