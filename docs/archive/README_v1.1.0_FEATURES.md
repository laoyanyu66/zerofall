# ZeroFall v1.1.0 新功能说明

## 🎯 启动自检加载进度条（ACE风格）

启动时会自动显示全屏加载界面，实时展示自检进度：

### 自检项目（11项）
1. ✓ 系统配置加载
2. ✓ 日志引擎初始化  
3. ✓ DeepSeek路径检测
4. ✓ 插件目录扫描
5. ✓ 快照索引加载
6. ✓ MD5基线校验
7. ✓ 会话完整性校验
8. ✓ 环境健康评估
9. ✓ 守护进程初始化
10. ✓ 云端连接检测
11. ✓ 系统就绪检查

### 界面特点
- 深色科技风格主题
- 渐变色进度条
- 实时百分比显示
- 每个检查项的状态图标（✓通过 / ⚠警告 / ✗失败）
- 自检完成后自动切换到主界面

## 🖥️ 系统托盘图标优化

### 强制显示在任务栏
- 使用 Windows 原生 API 创建托盘图标
- 图标始终显示在任务栏右下角
- **不会隐藏在溢出菜单（小三角）中**

### 托盘功能
- 左键双击：显示主窗口
- 右键点击：显示快捷菜单
  - 显示主窗口
  - 启动 DeepSeek
  - 退出

## 🚀 使用流程

1. **启动程序**
   - 双击 `ZeroFall.exe` 或桌面快捷方式

2. **等待自检**（3-5秒）
   - 查看自检进度
   - 确认所有检查项通过
   - 如有警告/失败，查看详细信息

3. **进入主界面**
   - 自检完成后自动切换
   - 可以开始使用所有功能

4. **后台运行**
   - 最小化后图标显示在任务栏
   - 随时双击托盘图标恢复窗口

## 💡 提示

- 首次运行建议在"设置"中配置 DeepSeek 路径
- 自检失败的项目会在主界面中详细说明
- 托盘图标始终可见，方便快速访问
